This installs the fully-integrated SentinelOS build onto a Google Pixel — the OS-level option. Just want monitoring on a phone you already use (any brand)? You don't need this — use the Device Owner agent install instead (no flashing, no wipe).
Your browser doesn't expose WebUSB. Use desktop Chrome, Edge, or another Chromium browser over HTTPS. Firefox and Safari are not supported.
Before you start
  • A supported Google Pixel with an unlocked bootloader (Settings → Developer options → OEM unlocking, then fastboot flashing unlock).
  • A USB-C data cable and desktop Chrome/Edge.
  • Flashing erases the device. Back up anything you need first. (This is different from the agent install, which does not wipe.)
  • You're signed in — this binds the device to your account and starts your 30-day OS trial.
