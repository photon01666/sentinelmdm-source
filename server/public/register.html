Why a word phrase? A short "P@ssw0rd1!"-style password only swaps a few characters for look-alike symbols — attackers already check those first. A handful of random, unrelated words has far more possible combinations per slot, no symbols required, and — unlike a string of substitutions — you can actually remember it.
This password is your encryption key All private data captured from your device (photos, audio, screen captures, location, etc.) is encrypted before it reaches the server using a key derived from this password. The server never stores your password or encryption key.

⚠️ If you forget this password, all encrypted data is permanently and irrecoverably lost. There is no "Forgot Password" reset. Write it down and store it somewhere safe.
