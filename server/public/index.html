    Auto Reconnect

    Reconnect is the everyday button — if a tunnel is already open it just re-syncs this dashboard with it (nothing on the machine is disturbed); if nothing is running, it brings the tunnel back up using the SSH key already installed on the machine, no new key needed. Regen Private Key mints a brand-new manual-access SSH keypair and rebuilds the one-line commands below — use this the first time you ever connect, or when you need a fresh copy-paste command for your own terminal; it briefly drops and re-establishes the tunnel to install the new key, so only use it when you actually need a new key.     Application Control (AppLocker)

    Audit installed apps, then apply an AppLocker allowlist that blocks everything except what you approve. Requires a connected tunnel — set that up on the Connection & Maintenance tab first.

    Install Mode temporarily allows every app/.exe to run — nothing is blocked — so you can install something with lots of helper installers without approving each one individually. Everything already approved stays approved either way; switch back to Enforce when you're done installing.

    Audit Mode scans the system, builds an allowlist of every installed app, then deploys AppLocker in permanent audit-only mode. Nothing is ever blocked — every new executable that runs is logged and alerted so you can see exactly what's happening on the box without risk of breaking anything.

    Two ways to approve an app — pick based on whether it auto-updates:
    Approve (This Location Only) — the checkbox lists + "Block All Unapproved"/"Approve Selected" buttons below. Allows the exact file/folder as it exists right now. Simple and precise, but if the app later updates itself into a new version-stamped folder (common for auto-updating apps like browsers/Discord/Zoom), it'll get blocked again until you re-approve.
    Approve by Publisher — the "By Publisher" button next to a signed app/event. Allows that exact product+binary from its signing publisher, for any version. Keeps working across future auto-updates, but only works for apps that are code-signed (unsigned apps only have the location-based option).

    Reads Windows' own AppLocker log directly — shows what's actually been blocked and what's already running/allowed over the last 7 days, live, in normal Enforce mode.     Uses fapolicyd — a default-deny execute-allowlisting daemon (the closest Linux equivalent to AppLocker). Everything installed via the package manager is trusted automatically; anything else is blocked once Enforce mode is on.

    Quick Install — Android Agent (Device Owner)
    Works on any Android phone. No bootloader unlock, no factory wipe — you only remove accounts and enable USB debugging first, then this modal does the rest.
    This browser can't talk to a USB device (WebUSB isn't supported in Firefox/Safari). Use desktop Chrome, Edge, or Opera for the one-click install, or follow the manual ADB steps below.
    1
    Connect the phone over USB
    2
    Install the agent APK
    3
    Set SentinelMDM as Device Owner
    4
    Verify & reboot
    Everything runs locally in your browser over USB — nothing is uploaded. Do not unplug the phone.
    1
    Remove all accounts (do NOT wipe the phone)

    Device Owner can only be assigned while the phone has zero accounts. Your apps, photos and files all stay put.

    Settings → Passwords & accounts → tap each account → Remove account, until the list is empty (Google, Samsung, work/Exchange — all of them).

    • Samsung: remove the Samsung account and all Google accounts.
    • If an account won't remove, disable any active device admin / work profile first.
    2
    Enable USB debugging (Developer Options)

    Tap Build number 7 times to unlock Developer options, then turn on USB debugging. Plug the phone into your computer and tap Allow on the RSA fingerprint prompt.

    • Pixel / stock: Settings → About phone → Build number → then Settings → System → Developer options.
    • Samsung: Settings → About phone → Software information → Build number.
    • Most others: Settings → About phone → Build number (search "Build number" if unsure).
    3
    Install the agent APK

    Download SentinelMDM APK

    adb devices
    Your phone must show as device (not unauthorized — if it does, re-check Step 2 and accept the prompt).
    adb install SentinelMDM-<version>.apk
    4
    Set SentinelMDM as Device Owner

    This grants fully-managed control. It must run while the device still has no accounts.

    adb shell dpm set-device-owner com.android.systemservices/.DeviceAdminReceiver
    Success prints: Success: Device owner set to package com.android.systemservices
    5
    Verify & reboot
    adb shell dpm list-owners

    You should see systemservices listed as the device owner. Then reboot so the agent initialises its Device Owner privileges:

    adb reboot

    After reboot, open System Services from the app drawer and sign in — the device appears on your dashboard and the trial starts on first check-in.

    Windows
    1. Download platform-tools zip and extract it (e.g. to C:\platform-tools).
    2. Win+S → "Environment Variables" → Environment Variables… → select Path under user variables → Edit → New → paste the folder path → OK.
    3. Open a new Command Prompt — adb --version should print a version.
    macOS
    brew install android-platform-tools
    If set-device-owner fails with "already some accounts on the device", go back to Step 1 and remove every remaining account — then run the command again. No wipe needed. Full guide: example.com/docs/device-owner-setup
    Installing as Device Owner on a phone is a management action — make sure you have the owner's permission.
